# Changelog

## 0.1.0 — 2026-10-29

First release.

- Seven audits: confound, nuisance, protocol, leakage, drift, spectral, replay.
- Recording-level label permutation tests with Holm correction and Besag–Clifford early stopping.
- Joint leave-A-and-B-out protocol (e.g. unseen session *and* unseen object).
- Loaders for `.npz`, `.csv`, `.tsv`, `.parquet`; LeRobot v2.1 / v3.0 adapter (local or Hub, parquet only).
- Text, JSON and self-contained HTML reports (light/dark); CI-friendly exit codes.
- Synthetic shaking-box benchmark with four planted-shortcut scenarios.
